Built in a team of four; I engineered the Go WebSocket hub for real-time spatial sync, the JWT authentication system with email verification, TOTP-based two-factor authentication, and the chat and friendship features.

A custom HTTP/1.1 server written from scratch in C++98, inspired by NGINX. Handles multiple concurrent connections via I/O multiplexing, serves static content, executes CGI scripts, and processes GET, POST, and DELETE methods based on a configuration file. Built with a full test suite for config parsing and request handling.

A Bash-like Unix shell implementing pipes, redirections, heredocs, environment variable expansion, and signal handling, with no external parsing libraries and zero memory leaks. Built in a team of two; I designed the lexer/parser pipeline and the full expansion system. Bonus: logical operators, subshells, and wildcard globbing.

A complete LEMP stack deployed entirely from scratch using Docker containers. Every Dockerfile is built from a base image — no pre-made images. NGINX serves as a TLS-terminating reverse proxy over an isolated internal network, with MariaDB and WordPress orchestrated via Docker Compose. Includes dedicated developer and user documentation.
